# LZ 服务管理控制台 (Termux)

专为 Termux 打造的多服务一键启动与可视化管理面板。内置多节点容灾、双下载引擎、开机自启，开箱即用。

## ✨ 核心功能

- **开机自动弹菜单**：重启 App 后自动进入面板，15 秒无操作自动全量启动所有服务。
- **一键管理**：快速启动（仅补未运行）、停止全部、重启全部。
- **单服务操作**：可单独启动、停止、重启指定编号的服务。
- **实时状态**：菜单顶部实时显示所有服务的端口运行状态（绿色运行中 / 红色未运行）。
- **日志中心**：内置日志查看（`tail -f` 实时刷新）和一键清空日志。
- **环境自检**：完整启动时自动检查并安装缺失依赖（PHP、Node.js、Python、Go、ttyd 等）。
- **数据保护**：自动修复洛雪音乐缓存/音源软链接，自动桥接二进制文件到私有目录，防止安卓权限问题。
- **双下载引擎**：本地更新时，自动检测 `curl` 或 `wget`，哪个能用用哪个，互为备份。
- **多节点容灾**：内置 5 个公共代理节点，原站超时自动切换备用节点，彻底解决网络波动问题。

## 🚀 一键部署（Termux 终端直接执行）

支持 `curl` 和 `wget` 双引擎，复制其中任意一行命令执行即可。

**使用 curl 版本（推荐）：**

```bash
curl -fsSL "https://tvv.tw/raw.githubusercontent.com/wodecodeya/deploy-hub/main/lz-termux/install.sh" | bash
```

**使用 wget 版本（备用）：**

```bash
wget -qO- "https://tvv.tw/raw.githubusercontent.com/wodecodeya/deploy-hub/main/lz-termux/install.sh" | bash
```

部署完成后：
- 重启 App → 自动进入控制台（15 秒倒计时）
- 任意终端输入 `lz` → 秒进菜单
- 在菜单按 `U` → 自动尝试 5 个公共代理节点拉取更新

## 🎮 使用说明

- **首次打开**：终端出现菜单，底部有 15 秒倒计时。
  - 等待 15 秒无操作 -> 自动执行完整启动（检查依赖、修复软链接、全量启动服务）。
  - 按任意键 -> 进入主菜单，不再自动启动。
- **手动呼出**：在任何终端输入 `lz` 回车，秒进菜单（不会倒计时，不会全量重启）。
- **常用操作**：
  - 按 `A`：快速启动（只补未运行的服务，最快）。
  - 按 `K`：完整启动（全套自检 + 全量重启）。
  - 按 `U`：从 GitHub 拉取最新脚本（带多节点容灾）。
  - 按 `Q`：退出菜单，回到普通终端。

## 🛠 高级自定义

所有服务的定义都在脚本开头的 `SERVICES` 数组里，格式如下：

```bash
"编号|名称|端口|进程匹配|日志文件名|启动命令"
```

例如，如果你想新增一个名为 `myapp`、端口 `9090` 的服务，只需要在数组里加一行：

```bash
"12|我的应用|9090|myapp|myapp.log|cd ~/myapp && nohup ./myapp > $LOGDIR/myapp.log 2>&1 &"
```

修改后，按 `U` 更新脚本，或者重新下载覆盖即可生效。

## ⚠️ 注意事项

1. **需要存储权限**：首次使用需确保 Termux 已获取存储权限（`termux-setup-storage`）。
2. **防休眠**：脚本会自动执行 `termux-wake-lock`，防止系统休眠导致服务掉线。不建议手动 `termux-wake-unlock`。
3. **代理说明**：一键部署和更新命令中使用了 `tvv.tw` 等公共代理加速 GitHub 访问。公共代理可能随时失效，脚本内置了自动降级机制，会依次尝试 `tvv.tw`、`lalifeier`、`ghproxy.net` 等多个节点。
4. **兼容性**：仅支持 Termux 安卓环境，需要 `bash` 运行（不要用 `sh` 执行脚本）。
5. **更新机制**：菜单中的 `U` 功能会优先尝试直连 GitHub，如果超时或失败，会自动切换到备用代理节点。临时文件存放在 `$HOME` 目录，不会触发安卓对 `/tmp` 的权限限制。
